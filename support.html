Everything you need

ClipChain packs a powerful set of features designed for speed, privacy, and collaboration.

Instant Sync

Type on one device and it appears everywhere instantly via Firebase Realtime DB.

Rich Markdown

Format text with headings, bold, italic, code blocks, tables, colors, and custom fonts.

Passcode Security

Protect your clipboard with a password. Unauthorized users see a lock screen.

Self-Destruct

Set a countdown timer. The clipboard wipes itself after 10 mins, 1hr, or 24hrs.

Frequently Asked Questions

Click the QR Code button in the bottom dock to scan a share code directly, or click Copy Link next to your clipboard URL. Opening that link on any device connects it to your sync pool automatically.

Click the Notes icon in the bottom dock. A floating panel opens on the right. You can create multiple colorful sticky notes (baby blue, red, pink, purple, green, yellow), add a heading, write content, and pin them to the edge of the screen for quick reference.

Press ⌘K (or Ctrl+K on Windows) to open the floating Command Palette. Search and execute actions like creating notes, switching rooms, exporting, toggling themes, or locking your clipboard. Also includes a built-in Calculator and Calendar.

When a passcode is assigned, visitors see a lock overlay and cannot view or edit the content. The clipboard only loads after the correct password is verified. You can also remove the password at any time from the lock button in the toolbar.

Click the Export button in the bottom dock, or use ⌘E via the Command Palette. Your clipboard downloads as a .md file with your formatted markdown content preserved.

Multi-Clipboard Tabs let you run separate clipboards inside the same room — like browser tabs. Create tabs named "Work", "Code", "Links", etc., each with their own independent content that syncs separately in real-time.
